This repository is an entry to the make.fun bounty "Sum up 25 November's world news in one image" (https://make.fun/bounty/news-image-20261125); the program main.ts copies entry.png — a one-image summary of the world news of Wednesday 25 November 2026, drawn by gen_image.py — into the output directory. The image covers new US tariffs, strikes on two Samara refineries, an Israeli strike in Gaza's Shati camp, the Shenzhou-24 launch, the Iowa lead-azide detonation, and Bangladesh's garment wage rise.

## Run it

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
